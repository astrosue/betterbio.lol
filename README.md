# 💎 betterbio.lol
Забудь про скучные профили. **Betterbio** — это ультимативный движок для тех, кто хочет выделяться. Сделай свою визитку за 2 минуты, а не за 2 часа.

> "Guns.lol, только лучше." — (с) Твои будущие юзеры.

### ⚡ Почему лучше?
- **No bloat:** Только нужные фичи.
- **Custom CSS:** Поддержка своих стилей из коробки.
- **Customization:** Кастомизация за счет поддержки добавления любых js скриптов, разметок html и оформление к ним в css

### 🛠 Установка
Качаешь и файлы на хост кидаешь, конфиг поправляешь и отдыхаешь. Усе, проще уж некуда
